# Security Research

This directory is for sanitized research notes and case studies that are safe to publish.

For each write-up, document:
1. Context and authorization/disclosure status
2. Affected security property
3. Testing approach
4. Minimal, sanitized evidence
5. Verified impact and limitations
6. Recommended remediation
7. References, where appropriate

Do not publish credentials, tokens, personal data, client-confidential details, private program information, or unresolved vulnerability details without explicit authorization.
