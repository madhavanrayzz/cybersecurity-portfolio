# About Me

I'm Madhavan, a Security Analyst working in penetration testing. I focus on identifying and validating security weaknesses, understanding their practical impact, and communicating remediation clearly.

## Professional experience

I have independently handled penetration-testing engagements for **7+ clients**, taking responsibility for the assessment lifecycle—including client meetings, test execution, vulnerability validation, report preparation, and delivery coordination.

My work and learning focus on web application and API security, infrastructure assessments, authentication and authorization, business logic, and security misconfigurations. I also pursue independent security research and bug bounty work, with **$4,000+ in bounty rewards**.

## Technical interests

- Security testing and reconnaissance automation

## How I approach security testing

I aim to combine systematic coverage with manual validation. Scanner output is a starting point, not a conclusion. A useful finding should be reproducible, have a clear explanation of impact, and include practical remediation guidance.
